# Portfólio pessoal — Vanessa

**Aluna:** Vanessa

## Descrição
Site de portfólio pessoal criado para apresentar perfil, projetos e atividades, habilidades, formação e contato. O conteúdo foi deixado editável para que as informações sejam preenchidas de acordo com a trajetória real da pessoa.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3

## Funcionamento
O `index.html` contém as seções do portfólio e o menu de navegação. O Bootstrap é utilizado para o menu responsivo, o sistema de colunas e os botões. O arquivo `css/style.css` define as cores, o layout e os efeitos visuais. O arquivo `js/script.js` atualiza o ano do rodapé e controla o botão de voltar ao topo.

## Recurso novo
Foi incluído um botão flutuante de “Voltar ao topo”, que aparece depois que a página é rolada.

### Como foi implementado
O JavaScript observa o evento `scroll` e adiciona ou remove a classe `show` conforme a posição da página. O CSS controla a visibilidade e a transição. Ao clicar, o botão utiliza `window.scrollTo()` com rolagem suave.

Também foram adicionados efeitos de `hover` nos cartões e nas habilidades.
